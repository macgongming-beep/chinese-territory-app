# 디자인 핸드오프 v2 — 화면 설명 (리더/봉사자 + 지도 + 기타)

> 어드민 23화면 핸드오프 완료 후, 남은 모바일 화면들의 역할/내용/액션 설명.
> 톤/간격/위계/인터랙션 등 시각적 판단은 디자이너 자율.
> 기능과 데이터 흐름은 코드에 살아있음 (스켈레톤 상태) — 시안 작업 시 실 데이터 흐름 확인 가능.

## 공통 컨텍스트

- 톤: Tone B 웜그레이 + ink 모노크롬, Pretendard Variable, letter-spacing -0.005em
- 어드민 23화면 핸드오프(`design_handoff_admin_redesign/`) 기준 유지
- 역할 구조:
  - `admin` — 전체 관리, 사용자/카드 배정
  - `leader` — 담당 카드 운영, 봉사 인도
  - `user` — 방문 기록, 일정 신청
- 어드민과 다른 점: leader/user 는 **본인이 직접 손에 쥔 데이터만** 본다. 회중 전체 KPI X, 사용자 관리 X.

## 24. 봉사자 홈

**역할** — 봉사자가 앱을 열었을 때 가장 먼저 보는 곳. "지금 뭐 해야 하지" 가 한눈에 보여야 함.

**사용자** — `user`, `leader` 공통 (leader 는 추가 모듈 25 참고)

**진입 경로** — 앱 진입 시 기본. 하단 탭 '홈'.

**주요 정보**
- 회중 공지 최근 1~3건 (제목, 작성일)
- 오늘 신청한/배정된 봉사 (시간, 장소, 인도자, 동행자)
- 정기방문 미리보기 — "다가옴" 우선순위 2~3건 (라벨, 주소, 마지막 방문 D-N)
- 오늘 진행한 봉사 세션 (시작/종료 상태, 카드명)
- 활성 세션이 있으면 "지금 기록하러 가기" 강조

**주요 액션**
- 공지 탭 → 공지 상세
- 오늘 봉사 탭 → 일정 상세 (시작/종료 가능)
- 정기방문 카드 탭 → 정기방문 상세 (화면 26)
- "전체 보기" 링크 → 활동 탭의 해당 섹션

**빈 상태**
- 공지 없음 / 오늘 일정 없음 / 정기방문 0건 — 각각 자연스러운 빈 카드
- 봉사자가 신규 가입자일 수 있음. 첫 정기방문 만들기 진입 동선 필요.

**연결**
- 일정 상세 (어드민 02b 재사용)
- 정기방문 상세 (화면 26)
- 활동 탭 (화면 27)
- 캘린더 / 지도 / 설정 탭

**제약/참고**
- 어드민/리더 대비 액션 수 적음 → 공백을 메우는 톤 디자인 필요
- 활성 세션 / 오늘 일정 / 정기방문 중 어느 모듈을 우선 노출할지는 디자이너 판단

## 25. 인도자 홈 (봉사자 홈 + 추가 모듈)

**역할** — 봉사자 홈을 기본으로 깔고, 인도자만 보이는 모듈 추가. 회중 전체가 아닌 **내가 인도하는 범위** 의 액션 항목.

**사용자** — `leader`

**진입 경로** — 앱 진입 시 기본. 하단 탭 '홈'.

**주요 정보 (봉사자 홈에 더해)**
- 오늘 내가 인도하는 봉사 (시간, 장소, 신청자 명단, 사용 카드)
- 신청자 알림 — 내 일정에 누가 새로 신청했는지
- 다가오는 내 일정 (이번주 인도 예정)

**주요 액션**
- 인도하는 봉사 → 일정 상세에서 시작/종료, 신청자 관리
- 신청자 알림 → 해당 일정으로 점프

**빈 상태**
- 인도 일정 0건 / 신청자 알림 0건 — 가벼운 톤
- 봉사자 홈 모듈이 fallback 으로 노출돼야 함 (인도자도 본인 정기방문 등 봉사자 모듈은 그대로 봄)

**연결**
- 일정 상세 (인도자 시점 — 신청자 관리/카드 연결 액션 노출)

**제약/참고**
- 담당 카드는 "구역" 탭에서 봄 → 홈에 카드 목록 모듈 없음
- 봉사자 모듈과 인도자 모듈 간 시각적 구분이 필요한지 디자이너 판단

## 26. 정기방문 상세 (풀스크린)

**역할** — 한 세대의 정기방문 히스토리/메모/액션 허브. 빠른 기록(미니 시트)과 별도로 깊게 회고/관리하는 곳.

**사용자** — `user`, `leader`

**진입 경로**
- 홈 정기방문 미리보기 카드 탭
- 활동 탭 정기방문 카드 본문 탭
- (옵션) 알림 → 정기방문 알림 탭

**주요 정보**
- 거주자 라벨 (별칭 또는 자동 라벨)
- 주소
- 결과 상태 (관심/연구/재방문 등) + 마지막 방문 D-N
- 평균 방문 간격 (3건 이상일 때) + 다음 권장일
- 방문 기록 타임라인 — 날짜, 결과(만남/부재), 메모, 작성자

**주요 액션**
- 빠른 기록 — 만남/부재 토글 + 메모 + 저장
- 지도에서 보기 (해당 건물 핀 focus)
- 별칭 편집 / 주소 편집
- 정기방문 해제 (삭제)
- 기록 항목별 편집/삭제

**빈 상태**
- 첫 기록 없음 — "아직 기록이 없습니다" + 입력 폼 직접 노출
- 정기방문 항목을 못 찾았을 때 — 안내 + 목록으로 돌아가기

**연결**
- 지도 탭 (해당 건물/주소 focus)
- 활동 탭 정기방문 목록

**제약/참고**
- 데이터 모델: `ReturnVisit` + `ReturnVisitLog[]`
- 별칭(`nickname`) 과 자동 라벨(`displayName`) 둘 다 존재. 사용자가 별칭 비웠을 때 displayName fallback
- 방문 결과는 만남/부재 2종만 현재 (추후 관심/연구 단계 추가 검토)
- "관계자 외 비공개 메모" 구분 없음 (현재는 단일 메모 필드)

## 27. 활동 탭 (봉사자/인도자 공통)

**역할** — 누적 활동 + 정기방문 + 지난 봉사 회고 허브. 홈이 "지금 해야 할 일" 이면, 활동은 "내가 뭘 했지" + "전체 리스트".

**사용자** — `user`, `leader`

**진입 경로** — 하단 탭 '활동'.

**주요 정보 (위에서 아래 위계)**
1. **배정된 봉사** — 오늘/곧 진행할 본인 배정 일정. 펼치면 인도자/동행자/사용 카드.
2. **정기 방문** — 메인 모듈. 전체 리스트 + 본문 탭 시 상세 진입(화면 26).
3. **지난 봉사 미니 캘린더** — 월 네비 + 그리드. 참여한 날 ink 채움. 탭하면 인라인 상세(시간대/인도자/동행자).

**주요 액션**
- 정기방문 카드 → 상세 진입 / 빠른 기록 / 지도 점프 / ⋮ (별칭·주소·삭제)
- 정기방문 추가 (+) — 수동 입력 시트
- 배정 카드 → 지도 점프
- 지난 봉사 셀 탭 → 인라인 상세 펼침

**빈 상태**
- 배정 0건 / 정기방문 0건 / 지난 봉사 0건 — 각각 자연스러운 빈 카드
- 정기방문은 "추가 +" 동선 강조

**연결**
- 정기방문 상세 (화면 26)
- 일정 상세 (어드민 02b 재사용)
- 지도 탭

**제약/참고**
- 정기방문은 색상 태깅 가능 (사용자 로컬 저장)
- 지난 봉사는 시간대 4종 이상도 표시 가능 (오전/오후/저녁/봉사모임 등) — 셀은 binary 채움만, 디테일은 탭 인라인

## 28. 리더 배정 화면 (내 카드 → 봉사자 분배)

**역할** — 인도자가 본인이 받은 카드를 그날 봉사자(또는 신청자)에게 다중 분배. 어드민의 "전체 카드 분배" 와 다른 시점.

**사용자** — `leader`

**진입 경로** — 하단 탭 '배정' (인도자만 보임).

**주요 정보**
- 내가 인도자로 받은 카드 목록 (지역/동/진행률/배정자)
- 카드 선택 시 — 그날 활성 봉사자 또는 신청자 풀
- 이미 다른 사람에게 배정된 카드는 상태 표시

**주요 액션**
- 카드 1개 선택 → 봉사자 다중 선택 → 일괄 배정
- 카드 단위 회수/재배정
- 어드민이 이미 배정한 카드를 다른 사람에게 위임 (보조 흐름)
- 일괄 취소

**빈 상태**
- 내가 받은 카드 0건 — "아직 받은 카드가 없습니다" + 어드민 문의 안내
- 활성 봉사자 0명 — "오늘 활성화된 봉사자가 없습니다"

**연결**
- 일정 상세 (어떤 일정에 카드를 연결할지)
- 구역 탭 (카드 상세 보기)

**제약/참고**
- 어드민 18/19 배정 화면 (`design_handoff_admin_redesign/html/18-19-*.html`) 참고하되 시점 다름
- "다중 선택 + 일괄 적용" 인터랙션 패턴 유지

## 29. 봉사자 캘린더 탭

**역할** — 봉사자가 일정을 보고 신청/취소하는 곳. 어드민과 달리 일정 생성/수정 권한 없음.

**사용자** — `user`, `leader`

**진입 경로** — 하단 탭 '캘린더'.

**주요 정보**
- 월별 캘린더 그리드 (어드민 02 재사용)
- 일정 점 표시 — 봉사 모임/일반 봉사 구분
- 본인 신청/배정 일정은 시각적으로 구분

**주요 액션**
- 일정 탭 → 일정 상세 시트 (어드민 02b 재사용)
- 일정 상세에서 신청/취소 (인도자/관리자 액션은 노출 X)

**빈 상태**
- 일정 없는 달 — 깔끔한 빈 캘린더

**연결**
- 일정 상세 시트 (어드민 02b 의 user 시점)

**제약/참고**
- 일정 생성 버튼 없음 (어드민/리더만)
- 일정 수정/삭제 액션 없음

## 30. 봉사자 설정 탭

**역할** — 본인 계정 / 알림 / 앱 정보 관리.

**사용자** — `user`, `leader`

**진입 경로** — 하단 탭 '설정'.

**주요 정보 (어드민 15+ 재사용)**
- 내 정보 (이름, 아이디, 비밀번호 변경)
- 알림 설정 (방해금지 시간, 푸시 권한)
- 언어 (개인별 저장)
- 앱 정보 (버전, PWA 업데이트)
- 특별봉사 시즌 (조회만)

**주요 액션**
- 내 정보 편집
- 알림 토글
- PWA 업데이트 버튼

**빈 상태** — N/A

**연결**
- 설정 하위 화면들 (어드민 핸드오프 15~17 재사용)

**제약/참고**
- 어드민과 차이: 사용자 관리, 시즌 생성/수정, 권한 변경 등 어드민 메뉴 미노출
- 디자이너가 어드민 설정 화면을 user 시점으로 어떤 항목 빼고 어떤 항목 남길지 정의

## 31. 지도 세대 결과 기록 시트

**역할** — 지도/카드에서 한 세대를 누른 뒤 결과를 입력하는 빠른 입력 시트. 가장 자주 쓰는 화면.

**사용자** — `user`, `leader`, `admin`

**진입 경로**
- 지도 탭에서 세대 마커 탭
- 카드 상세에서 세대 행 탭
- (옵션) 정기방문 상세에서 "기록" 버튼

**주요 정보**
- 세대 라벨 (건물명, 호수)
- 주소
- 최근 방문 기록 (있으면 1~2건 미리보기)

**주요 액션**
- 결과 chip 선택 — 만남 / 부재 / 관심 / 방문금지 / 정기방문 등
- 시간대 자동 추론 (현재 시각 기반) — 사용자가 수정 가능 (오전/오후/저녁)
- 방문자 본인 이름 자동 (수정 가능)
- 메모 (선택)
- "초대지 두고 옴" 토글
- 저장 → 시트 닫고 지도/리스트 복귀

**빈 상태** — N/A (항상 세대 컨텍스트 있음)

**연결**
- 정기방문 등록 흐름 (결과로 "정기방문" 선택 시)
- 방문 기록 누적 (visit_histories 테이블)

**제약/참고**
- 1탭 안에 끝나는 빠른 흐름이 중요 — 단계 늘리지 말 것
- 결과 종류는 일부만 빠른 입력에 노출, 나머지는 펼침 안에 (디자이너 판단)
- 초대지 두고 옴은 특별봉사 시즌일 때만 노출 (현재 정책)

## 32. 지도 핀 마커 + 클러스터

**역할** — 지도 위 세대/건물 표시. 상태 한눈에 + 줌 레벨별 변형.

**사용자** — `user`, `leader`, `admin`

**진입 경로** — 지도 탭, 카드 진입 시.

**주요 정보 (핀 한 개에 담길 것)**
- 위치
- 상태 — 방문필요 / 완료 / 방문금지 / 정기방문 / 관심 등
- 다중 세대(아파트) — 한 핀에 N세대 표시

**주요 액션**
- 핀 탭 → 결과 기록 시트 (화면 31) 또는 건물 peek (화면 33)
- 클러스터 탭 → 줌 인

**제약/참고**
- 어드민 23 핸드오프 명시: 14×14 droplet 모양, `borderRadius: 50% 50% 50% 0`, `transform: rotate(-45deg)`, 2px white border, 상태별 색
- 현재 코드 — `MapCanvas.tsx` 의 마커 렌더링. 디자이너 시안 따라 색/크기 조정 필요
- 클러스터 + 줌 레벨별 변형은 아직 미정 — 디자이너 제안 환영

## 33. 지도 건물 미리보기 (peek)

**역할** — 지도 핀을 탭했을 때 화면 하단에 살짝 떠 있는 미니 카드. 기록 시트(31) 와 다른 가벼운 정보 노출.

**사용자** — `user`, `leader`, `admin`

**진입 경로** — 지도 핀 탭 (다중 세대 건물일 때).

**주요 정보**
- 건물명 / 주소

## 34. 일정 상세 시트 — leader/user 시점

**역할** — 어드민 02b 일정 상세를 leader/user 시점으로 변형. 노출 액션이 다름.

**사용자** — `user`, `leader`

**주요 정보 (어드민 02b 동일)**

- **leader (본인이 인도자)**: 신청자 명단 수동 추가/제거, 카드 연결, 시간 마감, 메모 작성, 댓글, 채팅 열기
- **leader (참가자)**: user 와 동일

**빈 상태** — N/A

**연결**
- 카드 연결 → 구역 탭 카드 선택

- 댓글 → 인라인

**제약/참고**
