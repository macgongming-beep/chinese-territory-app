# PC 화면 정합성 감사

- 상태: **진행 중**
- 원본 요청: `review_tasks.id = 2`, `PC 화면`
- 요청 내용: 관리자·인도자 운영 화면 우선 정리 / 봉사자 나의 봉사는 배정 확인에 필요한 범위만 유지

## 왜 별도 작업인가

PC 화면에는 오래된 UI와 모바일에 먼저 적용된 기능이 함께 남아 있다. 색이나 간격만 고치면
기능 차이를 가린 채 낡은 동작을 유지할 수 있으므로, 요청을 단순 디자인 수정으로 닫지 않는다.

## 감사 범위

1. 관리자 홈의 승인 대기·자료 수정 요청·정기방문 관리 숫자와 이동 경로
2. 관리자·인도자의 지도, 구역, 배정 및 통계 업무
3. 건물·세대 추가 및 수정, 용도 선택, 출입불가, 안전 삭제 요청
4. 식당 등록·정기방문 등록의 검색 후보와 기존 건물 재사용
5. 설정 관리 화면의 정보 밀도와 처리 동선
6. 봉사자 나의 봉사의 일정·팀·구역 카드·식당 배정 표시
7. 한국어·중국어·영어 번역 누락과 모바일 전용 문구의 PC 대응

## 완료 조건

- 기능 차이 목록을 먼저 만들고 각 항목을 `동기화 / PC 전용 유지 / 제거`로 결정한다.
- 공통 로직은 같은 유틸이나 서버 RPC를 사용하며 화면별 복사 판정을 만들지 않는다.
- 오래된 UI를 고치는 동안 모바일 동작과 운영 자료 계약을 바꾸지 않는다.
- 원본 `PC 화면` 요청은 감사와 필요한 수정이 끝난 뒤에만 완료 처리한다.

### 권한 계약

- 관리자는 현재 화면 모드와 관계없이 일정 배정에서 모든 구역을 볼 수 있다.
- 인도자는 자신이 일정 인도자인 경우에만 배정 편집기를 열고, 자신이 장기 담당한 구역만 배정할 수 있다.
- 공유 저장은 서버의 `assignmentSharedAt`을 비교해 다른 사용자의 변경을 조용히 덮지 않는다.
- 건물 정보와 담당 카드 수정은 서버가 실제로 한 행을 바꾼 경우에만 성공으로 처리한다.
- 지도 핀 이동도 서버 저장이 성공한 경우에만 성공 알림을 표시한다.
- 구·동을 직접 선택한 상태에서는 자동 줌 단계가 선택 범위를 해제하거나 상위 지역으로 되돌리지 않는다.

### 1차 수정 계약

- 한 일정의 배정 수는 구역 카드, 비공식 자료, 식당을 모두 합친다.
- 각 항목은 종류를 명확히 표시하고 해당 지도·자료·길찾기로 이동한다.
- 봉사자는 별도 PC 지도 메뉴 없이 나의 봉사에서 배정받은 항목을 눌러 진입한다.
- 배정 항목에서 연 지도는 기존처럼 본인 배정 카드와 최근 봉사 카드 범위만 보여준다.
- PC 후속 작업은 관리자·인도자의 운영 빈도가 높은 화면부터 진행한다.
