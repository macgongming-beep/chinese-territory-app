# PC 화면 정합성 감사

- 상태: **후속 작업 대기**
- 원본 요청: `review_tasks.id = 2`, `PC 화면`
- 요청 내용: 관리자 홈, 봉사자 홈 정리 / 봉사자 나의 봉사를 모바일과 맞추기

## 왜 별도 작업인가

PC 화면에는 오래된 UI와 모바일에 먼저 적용된 기능이 함께 남아 있다. 색이나 간격만 고치면
기능 차이를 가린 채 낡은 동작을 유지할 수 있으므로, 요청을 단순 디자인 수정으로 닫지 않는다.

## 감사 범위

1. 관리자 홈의 승인 대기·자료 수정 요청·정기방문 관리 숫자와 이동 경로
2. 봉사자 홈과 나의 봉사의 일정·팀·구역 카드·식당 배정 표시
3. 지도 검색, 주택/상가 필터, 혼합 건물 진행률과 핀 판정
4. 건물·세대 추가 및 수정, 용도 선택, 출입불가, 안전 삭제 요청
5. 식당 등록·정기방문 등록의 검색 후보와 기존 건물 재사용
6. 한국어·중국어·영어 번역 누락과 모바일 전용 문구의 PC 대응
7. 모바일에는 있으나 PC에 없거나, 같은 이름인데 동작이 다른 기능 목록

## 완료 조건

- 기능 차이 목록을 먼저 만들고 각 항목을 `동기화 / PC 전용 유지 / 제거`로 결정한다.
- 공통 로직은 같은 유틸이나 서버 RPC를 사용하며 화면별 복사 판정을 만들지 않는다.
- 오래된 UI를 고치는 동안 모바일 동작과 운영 자료 계약을 바꾸지 않는다.
- 원본 `PC 화면` 요청은 감사와 필요한 수정이 끝난 뒤에만 완료 처리한다.
