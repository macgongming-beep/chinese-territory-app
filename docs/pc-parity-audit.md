# PC 화면 정합성 감사

- 상태: **진행 중**
- 원본 요청: `review_tasks.id = 2`, `PC 화면`
- 요청 내용: 관리자 홈, 봉사자 홈 정리 / 봉사자 나의 봉사를 모바일과 맞추기

## 왜 별도 작업인가

PC 화면에는 오래된 UI와 모바일에 먼저 적용된 기능이 함께 남아 있다. 색이나 간격만 고치면
기능 차이를 가린 채 낡은 동작을 유지할 수 있으므로, 요청을 단순 디자인 수정으로 닫지 않는다.

## 감사 범위

1. 관리자 홈의 승인 대기·자료 수정 요청·정기방문 관리 숫자와 이동 경로
2. 봉사자 홈과 나의 봉사의 일정·팀·구역 카드·식당 배정 표시
3. 지도 검색, 주택/상가 필터, 혼합 건물 진행률과 핀 판정
4. 건물·세대 추가 및 수정, 용도 선택, 출입불가, 안전 삭제 요청
5. 식당 등록·정기방문 등록의 검색 후보와 기존 건물 재사용
6. 한국어·중국어·영어 번역 누락과 모바일 전용 문구의 PC 대응
7. 모바일에는 있으나 PC에 없거나, 같은 이름인데 동작이 다른 기능 목록

## 완료 조건

- 기능 차이 목록을 먼저 만들고 각 항목을 `동기화 / PC 전용 유지 / 제거`로 결정한다.
- 공통 로직은 같은 유틸이나 서버 RPC를 사용하며 화면별 복사 판정을 만들지 않는다.
- 오래된 UI를 고치는 동안 모바일 동작과 운영 자료 계약을 바꾸지 않는다.
- 원본 `PC 화면` 요청은 감사와 필요한 수정이 끝난 뒤에만 완료 처리한다.

## 1차 감사 결과

| 영역 | 확인한 차이 | 결정 | 상태 |
| --- | --- | --- | --- |
| 봉사자 지도 | 본인에게 허용된 카드만 보여주는 PC 지도 로직은 있지만 사이드바 진입점이 없음 | 모바일처럼 지도 탭 제공 | 수정 |
| 나의 봉사 배정 | PC는 구역 카드만 계산해 비공식·식당 배정이 일정 합계와 상세에서 누락됨 | 모바일과 같은 세 종류를 한 일정에 표시 | 수정 |
| 나의 봉사 제목 | 사이드바는 `나의 봉사`, 본문은 `활동`으로 다름 | `나의 봉사`로 통일 | 수정 |
| 관리자 알림 | 가입 신청·자료 수정·정기방문 재지정 숫자가 PC 설정 사이드바에도 연결됨 | 현행 유지 | 확인 완료 |
| 지도 용도 필터 | PC 지도도 공통 `buildingHasUsage`를 사용함 | 현행 유지, 화면별 숫자만 후속 점검 | 확인 완료 |
| 정기방문 | PC 나의 봉사에는 목록·기록이 있으나 추가·종료·장소 수정 요청 흐름은 모바일에만 있음 | 다음 묶음에서 동기화 | 대기 |
| 식당봉사 | PC는 일정 배정만 보이고 탐색·방문 기록·추가 신청 흐름은 모바일에만 있음 | 사용 빈도와 화면 폭을 고려해 PC 흐름 설계 | 대기 |
| 설정 하위 화면 | 모바일 컴포넌트를 640px 폭으로 감싼 화면이 많아 PC 정보 밀도가 낮음 | 기능 계약 확인 뒤 PC 레이아웃으로 정돈 | 대기 |

### 1차 수정 계약

- 한 일정의 배정 수는 구역 카드, 비공식 자료, 식당을 모두 합친다.
- 각 항목은 종류를 명확히 표시하고 해당 지도·자료·길찾기로 이동한다.
- 봉사자 PC 지도는 기존처럼 본인 배정 카드와 최근 봉사 카드 범위만 보여준다.
- 지도 진입점을 추가해도 서버 권한과 실제 표시 범위는 넓히지 않는다.
