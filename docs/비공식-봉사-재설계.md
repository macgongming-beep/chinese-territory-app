# 비공식 봉사 — 사진에서 지도로 (재설계)

> 2026-08-22 구상. 1단계 진행 중.
> 결정한 사람: 사용자. 이 문서가 방향의 기준이다 — 생각이 바뀌면 여기부터 고친다.

## 왜 바꾸나

지금은 비공식 봉사 장소를 **사진**으로 알려 준다. 대학 캠퍼스 안의 특정 지점
(`명지대(함박관)`, `단국대(스타벅스)`)을 사진으로 보여 주고 "여기로 가세요" 하는 방식이다.

문제가 셋이다.

1. **사진은 위치를 알려 주지 못한다.** 처음 가는 형제는 사진만 보고 못 찾는다.
2. **스토리지가 필요하다.** 회중마다 버킷·정책을 따로 만들어야 하고
   (다른 회중 설치 절차가 하나 늘어난다), 무료 500MB 에서 제일 빨리 차는 것도 사진이다.
3. **이 앱엔 이미 지도가 있다.** 건물·구역선을 다루는 도구가 그대로 있는데 안 쓰고 있다.

지도 핀으로 옮기면 셋이 한꺼번에 풀린다.

## 무엇을 만드나

### 데이터 — 새 표를 만들지 않는다

지금 표에 칸만 더한다. 기존 자료 13개와 지난 배정 9건이 그대로 살아 있어야 한다.

```
informal_groups          경희대 · 명지대 · 단국대 · 용인대 · 강남대   (그대로)
  └ informal_assets      명지대(함박관)
       name              (그대로)
       image_url         (그대로 두되 이제 선택 — 옮기는 동안 같이 보인다)
     + lat, lng          핀
     + memo              '1층 카페 앞. 점심때 사람 많음'
     + boundary          구역선  [{lat,lng}, …]
     + route             동선    [{lat,lng}, …]   ← 같은 형식, 닫지 않는다
     + zoom              비우면 자동 맞춤
```

**`boundary` 와 `route` 가 같은 형식인 것이 핵심이다.** 점을 찍고·옮기고·지우는
도구를 한 번만 만들면 둘 다 된다. 구역선은 `Polygon`(닫힘), 동선은 `Polyline`(열림)으로
그리기만 다르다.

### 화면

**지도** — 비공식 켜기/끄기 토글 하나

| | |
|---|---|
| 핀 | 구역 마커와 안 섞이게 다른 색 |
| 구역선 | 연한 채움 |
| 동선 | 화살표 선 (`naver.maps.PointingIcon.OPEN_ARROW`) + Ⓐ Ⓑ Ⓒ |

**만들기** — 지도에서 [비공식 장소 추가] → 클릭으로 핀 → 이름·메모 →
(원하면) 구역선·동선 그리기

**줌** — 대부분 손댈 필요가 없다. 구역선이나 동선이 있으면 `fitBounds` 가
도형에 맞춰 알아서 정한다 (캠퍼스는 멀리, 카페는 가까이). 핀만 있거나 직접 정하고
싶을 때만 `zoom` 을 채운다.

> 숫자를 입력하게 하지 말 것. 아무도 `17` 이 얼마만큼인지 모른다.
> **지도를 원하는 만큼 맞춰 놓고 [지금 보이는 만큼으로 저장]** 이 직관적이다.

### 권한

**관리자·인도자만** 만들고 고친다. 봉사자 제안 흐름은 두지 않는다 (2026-08-22 결정).

## 단계

```
1단계   핀 + 메모                     ← 사진 의존 제거. 다른 회중 설치 절차도 하나 줄어든다
2단계   구역선 + 동선(화살표)           ← 그리기 도구를 한 번에 재활용
3단계   A·B·C 라벨
4단계   사진 정리 (스토리지 비우기)      ← 핀이 자리잡은 뒤에
```

2단계를 쪼개지 않는다. 같은 도구를 두 번 손대는 것이 더 비싸다.

## 옮길 때 주의

- **기존 자료를 지우지 말 것.** `event_informal_assignments.asset_id` 가
  `on delete cascade` 라, 자료를 지우면 **지난 배정 9건(봉사 이력)이 같이 사라진다.**
  이름은 그대로 두고 핀만 찍는다. 13개라 한 번에 끝난다.
- **사진은 핀이 자리잡은 뒤에** 지운다. 그동안은 둘 다 보이게 둔다.
- 스토리지 버킷 정리는 마지막이다. 그때 다른 회중 설치 문서에서 ⑤단계를 지운다.
