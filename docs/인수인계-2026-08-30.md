## 이 저장소의 규칙 (어기면 조용히 샌다)

- **`security definer` 함수를 만들면 `revoke`.** PostgreSQL 은 만들 때 PUBLIC 에 준다.
  새로 만들 때마다 `supabase/tools/_AUDIT_anon이_부를수있는_definer.sql` 을 돌린다
- **시험을 쓴 뒤 코드를 일부러 망가뜨려 그 시험만 실패하는지 본다.**
  오늘만 헛도는 시험을 여섯 개 잡았다. 통과하는 시험과 무는 시험은 다르다
- **조립을 보는 시험이 없으면 배선이 끊긴 것을 못 잡는다.**
  편집기 단위 시험은 `initial.visitor` 를 직접 넣어 통과했는데, 정작 화면이 그 값을
  안 넘기고 있었다 — 열었다 저장만 해도 남의 기록이 되는 상태였다
- **화면에만 있는 권한은 권한이 아니다.** 표를 직접 쓰는 경로가 있으면 서버에서 막는다
- **`security definer` 안의 `current_user` 로 HTTP와 cron을 구분하지 않는다.** 항상
  함수 소유자로 보인다. cron과 UI가 공유하면 비공개 core + 검증하는 wrapper로 나눈다
- **SQL Editor 는 `begin/commit` 을 안 지킨다.** 위험한 마이그레이션은
  `npm run apply:lockdown` (psql `--single-transaction`)
- 비밀번호를 명령줄에 쓰지 않는다 (`.env.local` 의 `SUPABASE_DB_URL`)
